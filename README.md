## 💡 일하는 방식

- **다음 사람이 이어받을 수 있게** — 학생회는 매년 사람이 바뀌어서, 유지보수할 사람을 기준으로 기술을 고릅니다.
- **실제 환경에서 고친다** — 오래된 태블릿, 끊기는 Wi-Fi, 몰리는 동시 접속을 현장에서 겪고 고쳤습니다.
- **개인정보는 필요한 만큼만** — 학우들의 이름 · 학번 · 연락처를 다루기 때문에 최소 수집 · 최소 보관을 처음부터 설계에 넣습니다.
